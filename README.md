# Imperium Barber Club

Site de demonstração de uma barbearia premium, feito em HTML, CSS e JavaScript puro.

## Recursos

- Tabela de preços completa por categoria (cabelo, barba, combos, química, tratamentos, extras)
- Planos de assinatura mensais
- Equipe com especialidades e folgas
- Agendamento online em 4 etapas: serviços, profissional, data e horário, dados
- Horários calculados pela duração dos serviços, expediente e folga de cada barbeiro
- Confirmação enviada pelo WhatsApp e lista de "meus agendamentos" com cancelamento
- Galeria com filtros e lightbox, depoimentos, loja de produtos, FAQ e contato
- Status "aberto agora / fechado" em tempo real

## Personalizar

Número do WhatsApp, nome e horários ficam no objeto `CONFIG` no início de `js/main.js`.
Serviços, preços, barbeiros, produtos e FAQ ficam nas listas logo abaixo.
